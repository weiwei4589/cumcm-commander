# 支撑材料 — CUMCM提交物生成与合规检查

## 能力边界

- ✅ 扫描项目代码/图表目录，生成支撑材料ZIP
- ✅ 生成AI工具使用详情PDF（使用AI时）
- ✅ 生成支撑材料文件列表（供附录使用）
- ✅ 检查论文合规性：AI声明位置、文件大小、页数限制
- ✅ 输出可直接放入论文附录的文件列表文本
- ❌ 不负责生成论文正文或图表

## 使用场景

触发条件（任一）：
- 论文写完后说"生成支撑材料""打包提交物"
- 询问"还要交什么东西""提交规范是什么"
- 说"交卷检查""合规检查"
- 需要生成AI使用详情PDF

## 核心资源

| 类型 | 路径 | 用途 |
|------|------|------|
| 脚本 | `scripts/build_support.py` | 扫描+打包+生成文件列表（确定性执行） |
| 参考 | `references/2026_rules.md` | 2026年提交物规范（格式/内容/时限） |

## 工作流

### 第1步：确定项目根目录和AI使用情况

确认以下信息：
- 项目根目录（代码在 `code/`，图表在 `figures/`，论文在 `paper/`）
- 是否使用了AI工具（影响AI详情PDF是否需要生成）
- 若使用AI：工具名称、版本、使用目的

### 第2步：执行合规检查

**全部Python命令使用** `python`

检查项（按2026规则）：

| # | 检查项 | 标准 | 检查方式 |
|---|--------|------|---------|
| 1 | 正文页数 | ≤30页 | pymupdf读取PDF页数 |
| 2 | 论文大小 | ≤20MB | os.path.getsize |
| 3 | AI声明位置 | 参考文献**之前** | 读取Typst/PDF检查声明位置 |
| 4 | 附录完整性 | 含支撑材料文件列表+源代码 | 检查Typst源文件 |
| 5 | 身份信息泄露 | 摘要/正文/附录无学校/姓名 | 关键词扫描 |
| 6 | 页码 | 摘要页从"1"开始 | pymupdf页码验证 |

合规检查命令模板：
```bash
# 检查页数
python -c "import pymupdf; doc=pymupdf.open('paper/output_v2.pdf'); print(doc.page_count)"
# 检查大小
python -c "import os; print(os.path.getsize('paper/output_v2.pdf')/1024/1024)"
```

### 第3步：生成支撑材料

运行打包脚本：

```bash
cd {项目根目录}
python "<SKILL_ROOT>/scripts/build_support.py" . [--no-ai] [--output-dir submission]
```

参数说明：
- `--no-ai`：未使用AI（不生成AI详情PDF）
- `--ai-tool "DeepSeek"`：AI工具名称
- `--ai-version "V4-Pro"`：工具版本
- `--ai-purpose "论文写作辅助、代码调试、图表生成"`：使用目的

输出文件（在 `submission/` 目录）：
- `支撑材料.zip` — 打包后的提交文件
- `支撑材料文件列表.txt` — 可复制到论文附录的文件清单
- `AI工具使用详情.pdf` — AI使用详情（如使用AI）

### 第4步：将文件列表嵌入论文附录

读取 `submission/支撑材料文件列表.txt`，将其内容追加到论文Typst源文件的附录部分。格式：

```typst
== 附录D  支撑材料文件列表

（直接粘贴文件列表内容）
```

### 第5步：修正AI声明位置

**2026规则要求**：AI使用声明放在**参考文献之前**，不是之后。

检查Typst源文件：如果 `AI工具使用声明` 在 `= 参考文献` 之后，需要前移。正确顺序：

```
...模型评价与推广
= 结论
#pagebreak()
// AI声明放这里（参考文献之前）
#text(size: 10pt)[AI工具使用声明...]
= 参考文献
[1] ...
```

### 第6步：最终验证

全部完成后运行一次完整检查：
- 支撑材料ZIP存在且≤20MB
- 论文PDF存在且≤20MB
- 论文页数≤30
- 论文附录含文件列表
- AI声明在正确位置
- 无身份信息泄露

## 关键注意事项

1. **文件/文件夹命名**：不得包含参赛队号、学校、姓名。支撑材料ZIP内文件名同理。
2. **MD5码**：提交时需单独上传MD5码（不在此脚本范围内，需用竞赛管理系统客户端生成）。
3. **纸质版**：包含承诺书+编号页+摘要+正文+附录。本skill不生成纸质版，仅提示。
4. **源程序双重放置**：既要放在支撑材料ZIP中，也要作为附录放在论文中。
5. **时间线**：MD5码 9月13日20:00前 → 电子文档 9月13日20:30-14日14:00。

## 常见问题

**Q: 如果没有用到程序怎么办？**
A: 支撑材料可以不交。附录中写"本论文没有用到程序"。`build_support.py --no-ai`（注意：没有代码目录时会自动跳过）。

**Q: 支撑材料ZIP超过20MB怎么办？**
A: 脚本会自动警告。解决方案：压缩图表PNG分辨率（从300DPI降到200DPI），删除冗余文件。

**Q: 未使用AI需要AI详情PDF吗？**
A: 不需要。论文中声明"未使用任何AI工具"即可。`build_support.py --no-ai`。
