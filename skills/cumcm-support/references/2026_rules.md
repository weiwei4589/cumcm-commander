## 二、参赛论文格式

### 2.1 页面结构
1. 第一页：摘要专用页（含标题、摘要、关键词）— 从"1"开始编页码
2. 第二页起：正文（不超过30页，不要目录）
3. 正文之后：附录（页数不限）
4. 电子版不含承诺书和编号页

### 2.2 附录必须包含
- 支撑材料文件列表
- 建模所用全部完整可运行源程序代码
- 如确实没有用到程序，写明"本论文没有用到程序"

### 2.3 格式要求
- A4纸，上下左右≥2.5cm页边距
- 参考文献按科技论文规范，正文引用处标注
- 摘要页、正文、附录不得出现参赛者身份和学校信息

## 三、支撑材料内容

### 3.1 必须包含
- 所有可运行源程序代码（含EXCEL、SPSS等交互命令）
- 自主查阅使用的数据资料（赛题原始数据除外）

### 3.2 可选包含
- 较大篇幅中间结果图表
- 难以从公开渠道找到的相关资料
- AI工具使用详情.pdf（使用AI时强制）

### 3.3 禁止
- 文件/文件夹名出现参赛队信息
- 包含承诺书或编号页

## 四、AI工具使用规定（2026年试行）

### 4.1 论文中声明（放在参考文献**之前**）
> 注意：2025 版要求放在参考文献"之后"，2026 版已改为"之前"，切勿沿用旧位置（位置错 = 违反竞赛规则）。
- 未使用AI："本参赛队在竞赛过程中未使用任何AI工具。"
- 使用AI："本参赛队在竞赛过程中使用了AI工具，主要用于【用途】，详细使用情况见支撑材料。"

### 4.2 支撑材料中AI详情（仅使用AI时）
文件：AI工具使用详情.pdf
内容：
1. 所用AI工具名称、版本或型号
2. 具体使用目的和环节
3. 主要提示方式与使用过程说明（可附典型交互示例）
4. 对AI输出的采纳、人工修改和核验的主要情况（语言润色除外）

### 4.3 违规处理
- 故意隐瞒AI使用、虚假声明 → 取消评奖资格
- 未审查核实的AI生成内容作为核心成果 → 取消评奖资格

## 五、常见违规项

| 违规项 | 后果 |
|--------|------|
| 缺源程序或程序不能运行 | 可能取消评奖资格 |
| 论文和支撑材料出现学校/个人信息 | 可能取消评奖资格 |
| 正文超过30页 | 扣分 |
| 附录缺支撑材料文件列表 | 扣分 |
| AI声明位置错误（放在参考文献之后） | 格式违规 |
| MD5码与最终文件不匹配 | 提交无效 |
