# 数学建模国一专家

**唯一铁律（贯穿全程，优先级高于一切）**：范文和模板的优先级最高。写作的唯一标准是 `references/paper_skeleton.md`（= 用户模板《数学建模论文骨架谱系_国一标准.docx》的固化版）。凡本 skill 的任何内容与范文或模板冲突，一律以范文/模板为准。

**本 skill 只做两件事**：
1. **照模板写作，写完验收**——逐位置对照 `references/paper_skeleton.md`，每个位置照「主旨 + 功能要素 + 逻辑骨架」填，句式参照「句式样本」（范文原句，强推荐）；写完走五查验收。
2. **走工具链**——用规定的工具出图、排版、编译、核验，不搞野路子。

除此之外不提供任何写作建议、行为模式、题型套路。那些都作废了。

## 一、写作（唯一标准 = 模板）

- 动笔前，先读 `references/paper_skeleton.md` 全文。
- 写/改写任何一小节，先读这一小节的标题，确认它对应模板哪一章、哪一段、只写什么、不写什么。
- 每个位置照「主旨 + 功能要素 + 逻辑骨架」填，句数参考模板建议范围，句子自己组织。
- 每个位置的「句式样本」（范文原句 + 语感 + 落点）：**读它是硬的**（不读就不知道味道；范文库非空时，验收追溯表要能对上 `references/范文原文/` 里的原文）；**照抄是软的**（可模仿、可自写，句子自己组织）。人味规则（第二节 6 条）是大方向的强建议，提示规避什么。
- **范文库（可插拔，允许为空）**：`references/范文原文/` 是范文库目录，放入任意篇数的 `.md` 范文即生效（详见该目录 README）。**库为空时自动进入降级模式**（见 §二）——骨架、五查、铁律照常运行，只有"引用原文核对"改为"要素核对"，机制不失效。
- 写完必须走 §二 验收，两层都过才准交付。

## 二、验收（写完必做，独立 agent 验收）

- 验收清单（唯一）：`references/verification.md`，五查——查1过程痕迹 / 查2逐句追溯 / 查3效果达成 / 查4内容门禁 / 查5文件结构体检。
- **主写副验（硬规则）**：写完正文，必须起一个**全新的独立验收 agent**（用 Agent 工具），只喂它「产物 + 验收清单 + 模板路径 + 范文原文路径」，信息隔离。验收由这个副 agent 做，**写作 agent 不得自验**。
- 副 agent 的核对依据是范文库 `references/范文原文/` 里的原文——**引用对得上原文才算数**，不采信写作 agent 的"我读过了"自述。
- **范文库为空时进入降级模式**：查1 改为"核对追溯表是否逐位置落到骨架"，查2 删去"引用真实"一项、只留"每句有主 + 要素在清单内"；查3/查4/查5 强度完全不变。降级模式的验收反馈须首行标注「本篇运行于无范文降级模式」。
- 副 agent 写**简短反馈**（五查各是什么结果 + 结论：通过/不通过）。五查都过才准交付；任一不过写明"哪一查、哪一项、为什么"，打回写作 agent 重写，再验。**没有验收反馈 = 任务没完成**。禁止"看起来对"就宣布通过。

## 三、工具链（出图、排版、编译、核验）

- 工具路径、Python 路径、包版本、Typst/editor_sdk 编译命令：见 `references/tool_locations.md`。
- **Typst 排版头（最终修正版，写论文直接复制）**：见 `references/typst_setup.md`。
- 编译/排版常见坑（双编号、顶格、宽表等）：见 `references/troubleshooting.md`。
- 核验脚本：`scripts/audit_numbers.py`（论文数值 vs results CSV）、`scripts/pdf_check.py`（PDF 页数/图片）、`scripts/check_rationale.py`（扫描无依据的参数赋值）、`scripts/audit_docx.py`（docx 结构体检：分节符/公式图片/乱码/空格）。
- 代码模板：`references/code_templates.md`（三线表函数、matplotlib 配置等可直接复制）。

## 四、启动流程

1. 若本次任务涉及写论文，先读 `references/paper_skeleton.md`（唯一写作模板）。
2. 读 `references/tool_locations.md`，确认 Python 路径、包版本、编译方式（不要假设环境）。
3. 确认工作目录——读当前会话的工作目录，或问用户；若已有论文项目，用既有目录（如 paper_typst/），不新建时间戳文件夹。
4. 开始执行：**写作 agent** 写论文照模板 → 起**独立验收 agent** 走 §二 验收（主写副验）→ 出图/排版/编译/核验走 §三 工具链。
5. 每个有机位置都要写 + 验，不允许跳过任何位置，不允许"主 agent 自验"。

## 五、硬规则（不可违反）

- 交付走工具链（DOCX/editor_sdk 或 Typst/LaTeX），严禁 md→HTML→浏览器打印、截图拼接等野路子。
- **官方提交合规逐条过**：完整清单见 `references/paper_skeleton.md`「护栏五」。三条最易踩的硬红线——① **匿名**：摘要页/正文/附录/支撑材料内不得出现姓名、学校、赛区（含 PDF 属性、图片 EXIF、代码注释）；② **承诺书与编号专用页只属于纸质版**，电子版必须第一页即摘要页，支撑材料包内也不放；③ **论文 ≤20MB 且不压缩提交**、支撑材料包 ≤20MB。
- 正文必须有 **AI 工具使用声明**，位置固定在**参考文献之前**（官方 2026 强制，格式违规项）；使用 AI 时还须在支撑材料附《AI 工具使用详情.pdf》。模板句见 `references/paper_skeleton.md` 第 11 章。
- 正文页数按官方上限 **30 页**（摘要页与附录不计入）核对，用 `scripts/pdf_check.py`；字体是否按标准落地用 `scripts/font_check.py` 核（Typst 字体缺失会静默替换且不报错）。
- 修改/重写已有论文前，先列原论文完整结构清单，增删留痕说明理由。
- 验收全面扫描，禁止抽样假通过；五查任一 FAIL 打回重做。
- 缺附录完整源代码 = 可能取消评奖资格。
