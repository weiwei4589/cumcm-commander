# 参考论文样例

本目录包含一份达到国赛一等奖水平的完整论文样例。

## 文件说明

| 文件 | 说明 |
|------|------|
| `信用卡评分_参考论文.typ` | Typst 源文件，可直接编译。包含完整的三线表定义、中文题注、段落化创新点和模型评价 |
| `信用卡评分_参考论文.pdf` | 编译后的 PDF（22 页，正文 19 页），三线表、图表题注、公式排版均符合国赛标准 |
| `figures_png/` | 论文中引用的 10 张数据图（300 DPI PNG，供编译直接嵌入） |
| `figures/` | 同 10 张图的 PDF 矢量原件（存档用；注意 Python typst **不嵌入 PDF 矢量图**，要换成 PNG 再编译） |

## 编译与自检

```bash
# 编译（Python typst）
python -c "import typst; open('examples/信用卡评分_参考论文.pdf','wb').write(typst.compile('examples/信用卡评分_参考论文.typ'))"

# 自检：页数 / 体积 / 图片嵌入
python scripts/pdf_check.py examples/信用卡评分_参考论文.pdf

# 自检：中文字形是否真是宋体/黑体（防字体静默降级）
python scripts/font_check.py examples/信用卡评分_参考论文.pdf
```

> 本样例的字体已按 `typst_setup.md` 标准显式指定（正文 SimSun + Times New Roman、标题 SimHei）。
> 早前版本未设字体，中文实际渲染成楷体却看不出来——`scripts/font_check.py` 正是为抓这类"静默降级"而建。

## 这篇论文展示了什么

- **完整结构**：问题重述→假设→符号说明→数据预处理→WOE/IV筛选→逻辑回归评分卡→多模型对比→灵敏度分析→模型评价→结论→参考文献→附录
- **关键国一特征**：
  1. 摘要含具体数值（AUC=0.7655, KS=0.3837）
  2. 创新点段落化（4段，非 bullet）
  3. 模型假设两要素（内容+合理性）
  4. 灵敏度分析三层次（参数扫描+趋势图+统计检验）
  5. 多模型对比含 DeLong 检验和 GridSearchCV
  6. 模型评价段落化（优点5段+局限4段+推广5段）
  7. 全部表格为三线表
  8. 参考文献 13 篇，GB/T 7714 格式
- **数据规模**：438,557 条申请记录 + 15,277,108 条征信记录 + 629,487 条信用局评分
- **核心方法**：WOE 等频分箱 + IV 变量筛选 + 逻辑回归评分卡 + 四模型对比

## 如何使用这篇样例

1. 打开 `信用卡评分_参考论文.typ` 查看源码结构
2. 学习每个章节的写法、段落深度、图表分析句式
3. 将其中可复用的模式（三线表函数、题注规范、灵敏度分析模板）应用到你的论文中
