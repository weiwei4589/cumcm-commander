# 范文库（可插拔，本仓库为空）

本目录是骨架写作与验收的**范文库**。放入任意篇数的 `.md` 范文即生效；**允许为空**。

> 本仓库**不附带任何范文**（获奖论文属第三方作品，版权原因不分发）。请自备。

## 用途

「查 1 过程痕迹」「查 2 逐句追溯」的**逐字核对依据**：

- 写作时：读范文段落，学「松散罗列 / 直接陈述 / 思考外露」这些味道。
- 验收时：验收 agent 自己 Read 本目录的范文，把追溯表里的「范文引用」去掉空白后做子串比对——对得上 = 真读过；对不上 = 没读或编造，打回。

追溯表引用格式：`B046「求解无约束的方法各种各样……」段落，松散罗列风格`——记的是"参考了哪段的什么风格"，不是"逐字照抄哪句"。

## 两种运行模式

| 库状态 | 模式 | 行为 |
|---|---|---|
| 有 ≥1 个 `.md` | 完整模式 | 查1 / 查2 核对「引用能否对上原文」 |
| 空目录（本仓库默认） | **降级模式** | 查1 改为核对追溯表是否逐位置落到 `paper_skeleton.md`；查2 跳过「引用真实」项；查3/查4/查5 强度不变。验收反馈须注明「无范文降级模式」 |

降级只削弱"引用原文核对"这一项——骨架、五条铁律、五查验收整体照常有效，机制不失效。

## 自备范文怎么放

1. 把范文正文整理成 `.md`（一篇一个文件，文件名随意，建议用可辨识的名字）。
2. 从 PDF 提取的原文常带空格、标点噪声——核对时**去掉空白后再比对**，别因空格差异误判。
3. 一次放多篇更好：骨架是从多篇范文的交集里长出来的，单篇带偶然性。
4. 建议来源：公开赛事官方发布的获奖论文集（自行取得，自行合规使用）。

## 注意

- 本目录是范文的**核对基准存档**，不是写作模板；写作模板仍是 `../paper_skeleton.md`。
- 自备范文请自行确认使用范围；本仓库不对使用者放入的内容负责。
