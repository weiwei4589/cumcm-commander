# 数模指挥官 · 数学建模国一专家

本仓库包含**两个相互独立**的数学建模竞赛技能：

| 技能 | 定位 | 说明 |
|------|------|------|
| **数模指挥官** | 纯调度层 | 不含任何子技能。它教 AI 怎么干活：识别当前阶段、调配你已有的技能、守住五条铁律、拦截越界操作 |
| **数学建模国一专家** | 写作与交付 | 独立可用。国一论文骨架、逐句追溯验收、Typst 排版编译、四个核验脚本 |

两者可分别使用，没有依赖关系。你也可以只用国一专家写论文，或只用指挥官管流程。

## 这是什么

2026 年起，全国大学生数学建模竞赛（CUMCM）要求参赛队在论文中声明 AI 使用情况，并在支撑材料提交《AI 工具使用详情》；隐瞒或把未经人工核实的 AI 内容当核心成果，取消评奖资格。

赛场上真正的问题不是「AI 能不能用」，而是：**用了 AI，怎么保证论文还是你自己的？**

这两个技能分别解决其中一半：指挥官管流程与纪律，国一专家管写作与交付。

## 五条铁律（任何阶段生效）

| # | 铁律 | 含义 |
|---|------|------|
| 1 | 人是决策者 | 口径、选型、检验取舍只属于人；AI 输出一律是参谋意见，未过人脑仲裁不得进入论文 |
| 2 | 数值可溯源 | 论文中每个数字必须能追溯到 results CSV；`audit_numbers.py` 是死线前强制关卡 |
| 3 | AI 只修不写 | AI 改代码仅限接洽失败处，修完必须解释，人能复述才接受；禁止整段重写 |
| 4 | 拒绝假懂 | 任何人讲不清的模型/代码/公式，标记待补课，不进入定稿 |
| 5 | 主写副验 | 正文写完必须起独立验收 agent 四查，写作者不得自验 |

## 八阶段调度

```
0 赛前准备 → 1 读题翻译 → 2 建模思路 → 3 数据处理与求解
→ 4 论文写作 → 5 检验分析 → 6 全文合并 → 7 验收交卷
```

每个阶段都规定：人做什么、AI 做什么、本阶段红线。具体调用哪个技能由使用者自己决定——调度表只规定「该做什么、红线是什么」，不绑定具体工具。

## 校验脚本

机器可跑，把「隐性问题」变「显性检查」：

| 脚本 | 查什么 |
|------|--------|
| `audit_numbers.py` | 论文里的数字和 results CSV 逐一对账，对不上报错 |
| `audit_docx.py` | docx 结构体检：分节符、公式图片化、乱码、空格残留 |
| `pdf_check.py` | 正文页数（官方上限 30 页）、文件体积（不超过 20MB）、图片嵌入 |
| `font_check.py` | PDF 实际中文字形是否为宋体/黑体——Typst 字体缺失会静默替换且不报错 |
| `check_rationale.py` | 扫描无依据的参数赋值 |

## 快速开始

1. 把 `skills/` 下各目录放进你的 AI 客户端技能目录。
2. 从赛前准备阶段起，由「数模指挥官」接管流程调度。
3. 写论文时用「数学建模国一专家」：读骨架、逐位置写、独立 agent 五查验收。
4. 交卷前逐条过骨架文档里的「护栏五 · 官方提交合规」。

```
python >= 3.10
```

## 设计原则

- **官方合规与写作观感分离**：官方强制的（匿名、页数、AI 声明位置、支撑材料规范）集中在一处逐条硬性核对；写作层面的排版数值（字体、行距、三线表线宽）标明是国一专家技能自定标准、源自获奖范文惯用，官方对此不做统一要求。
- **技能可插拔**：调度层不依赖任何具体写作层实现；写作层的范文库由使用者自备（范文库留空时自动进入降级模式，骨架与验收照常运行）。
- **验收必须外部化**：写作者不得自验，验收 agent 拿客观依据（模板、骨架、自备范文）核对产物，不采信「我读过了」的自述。

## 与同类项目的区别

| | 目标 | 方向 |
|---|---|---|
| 常见 AI 论文工具 | 让 AI 更快写出论文 | 替人写 |
| **本仓库两个技能** | 让人在 AI 辅助下仍然写出自己的论文 | 管住 AI |
